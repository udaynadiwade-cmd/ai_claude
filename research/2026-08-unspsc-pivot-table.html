Same limitation as before — still true here

This covers 13 of the ~55 top-level segments in the full UNSPSC standard (10 through 26: raw materials, chemicals, heavy industrial and vehicle machinery). Segment 31 — Manufacturing Components and Supplies, where bearings, fasteners, gaskets and seals live — is not in this extract, and neither is anything from segment 27 onward (electronics, medical, IT, food, apparel, services). A category's absence from this tree is not evidence it doesn't exist; it may simply be outside segments 10–26.

Correction The earlier note counted 13,605 raw rows in the source file as commodity codes. 1,085 of those rows are section-boundary spacers with no commodity code attached — blank rows the original spreadsheet used to mark the end of a class or family. Once those are excluded, the real counts are 13 segments, 102 families, 973 classes, 12,520 commodities — the numbers this tree is built from.

Sources & method
UNSPSC UNv260801, founder-uploaded extract — research/data/unspsc-segments-10-26.csv, parsed with Python's csv module (not naive comma-splitting, since several titles contain commas inside quoted fields). 1,085 spacer rows with no commodity code excluded from all counts and from this tree.
Rows are sorted by descending code-count at every level, so the deepest, most-detailed parts of the taxonomy surface first when a branch is expanded.
To reach segment 31 and everything from 27 onward, the complete UNSPSC standard (all ~55 segments) is a free public download from UNDP (unspsc.org / undp.org/unspsc).
