# Outskill Mentor

A 15-day, 15-minutes-a-day mentor built from Uday's Outskill Generative AI
Bootcamp workbooks. One simple, practical question every morning at 9:00 AM
IST — never theory, always something he can use at Befach that day.

| File | What it is |
|---|---|
| [`CHARTER.md`](CHARTER.md) | How the mentor behaves — the daily loop, the hard rules |
| [`curriculum.md`](curriculum.md) | The 15-day plan, each day traced to a specific workbook |
| [`log.md`](log.md) | The running Q&A journal — questions asked, answers, feedback |

This track is separate from the Befach hiring work in the rest of this repo
(see root [`AGENT.md`](../AGENT.md)) — same repo, unrelated purpose.

Source workbooks live in Uday's Drive:
[🛠️ Hands-On Workbooks](https://drive.google.com/drive/folders/18KUAdu1otGg7PekyvnUJ8Gq3tGtjzlja).
Drop any new bootcamp workbook in there and the daily run will notice it and
propose where it fits.
